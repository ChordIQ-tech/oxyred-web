Carregar desgaste por posição

Cole o CSV ou o JSON do modelo (ou escolha um arquivo). Cada valor vira uma célula do revestimento do reator: fiada × setor.

Formato dos dados
  • Zonas: cuba_superior, cuba_inferior, ventaneiras, cadinho_parede, soleira. Use só as que tiver.
  • Fiada 1 = a mais baixa de cada zona. Na soleira, fiada 1 = anel central.
  • Setor 1 começa em 0° = furo de corrida, crescendo no sentido anti-horário visto de cima.
  • O número de fiadas e de setores é lido do próprio dado, em qualquer tamanho.
  • CSV: colunas zona,fiada,setor,valor e, opcional, corrida. Linhas # tipo=desgaste_mm, # espessura_inicial_mm=450, # limite_mm=300 definem a escala. Aceita ; e vírgula decimal.
  • JSON: snapshots com valores (matriz [fiadas][setores] por zona) ou o formato canônico zones + snaps.
  • tipo: desgaste_mm, espessura_residual_mm (exige espessura inicial) ou indice. limite_mm é o desgaste que vira vermelho.
Os dados carregados valem para este navegador. Ao integrar a medição real, o mesmo formato chega pelo contrato wear-dataset.schema.json.
